# ShipProven Homebrew tap

```sh
brew install verrian/shipproven/ship-proven
```

That installs the `ship-proven` terminal client. Homebrew downloads over
`curl`, which does not set `com.apple.quarantine`, so there is no
Gatekeeper prompt — unlike a browser download of the same binary.

## After installing

The client has no built-in cluster list, because the cluster is yours:

```sh
ship-proven cluster add <name> --issuer <url> --gateway <url>
ship-proven login
ship-proven mcp add <name> <url>      # optional, per MCP server
ship-proven shell
```

Your ShipProven contact supplies the issuer and gateway URLs for the
cluster you have been given.

## Upgrading

```sh
brew upgrade ship-proven
```

Deliberately the documented route. `ship-proven upgrade` also exists, but
it authenticates against a cluster to fetch the binary — so it cannot fix
a client whose stored credential is the thing that is broken. Homebrew
has no such circularity.

## What is in here

Only `Formula/ship-proven.rb`, which points at published, versioned,
checksummed binaries. The formula is regenerated by the ShipProven
release pipeline; the service source is not public.
